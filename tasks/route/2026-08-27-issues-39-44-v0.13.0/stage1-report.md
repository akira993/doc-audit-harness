S1 の着手準備として、計画書・現在の状態・基準テストを確認する担当を動かしました。

作業規約により、次の確認コマンドを実行する前に許可が必要です。いずれもファイルを変更せず、現状を確認するだけです。

- `git status --short`：未保存の変更がないかを確認します。
- `git branch --show-current`：現在の作業場所を確認します。
- `python3 -m unittest discover -s tests -t .`：変更前にテストが通るかと件数を確認します。
- `rg`／`sed`：計画書と対象ファイルの内容を読むだけです。
